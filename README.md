# 佐久間家ご飯マネージャー

お母さんの日々のご飯準備管理をスムーズにし、弟二人（かいり・いっけい）のご飯の要不要（⭕要る / ✖不要）をリアルタイムで共有・管理できるスマホ最適化Webアプリケーション（PWA対応）です。

## 特長
- セグメンテッドコントロールによる「一覧」「かいり」「いっけい」のワンタップ切替
- マスをタップするだけの簡単操作（空白 ➔ ⭕ ➔ ✖青）
- 各自のタブでのみ編集可能な安全な入力制限
- Firebase Realtime Databaseによる全スマホ間でのリアルタイム同期
- スマホのホーム画面に追加してアプリとして利用可能（PWA対応）
- かいり・いっけいタブの最下部に「母さんにギフトを送る」リンク配置

## 無料でGitHub Pagesにて公開する手順

1. このリポジトリをGitHubにコミット＆Pushします。
2. GitHubのリポジトリページを開き、「Settings」タブを選択します。
3. 左メニューの「Pages」を選択します。
4. 「Build and deployment」の Source で `Deploy from a branch` を選択し、Branch で `main` (または `master`) / `/ (root)` を指定して「Save」をクリックします。
5. 数分後に発行される公開URL（例: `https://<ユーザー名>.github.io/family-meal-app/`）にアクセスすることで、スマホから誰でもアプリとして利用できます！
